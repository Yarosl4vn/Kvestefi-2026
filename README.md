# Квестефи — подготовка к ОГЭ и ЕГЭ

Мобильное Android-приложение, которое превращает подготовку к экзаменам в ежедневный квест
и связывает учителя с классом. Проект команды **ReadySquad** для Всероссийского хакатона
по информационным технологиям 2026, направление **«Мобильная разработка»**.

* **Команда:** ReadySquad
* **Участники:** Акинфиев Ярослав Артемьевич (лидер команды, главный разработчик),
  Давлатов Хайдарали Абдулхамидович (разработчик)
* **Наставник:** Усенкова Жанна Михайловна
* **Версия приложения:** 4.0.0 (versionCode 40)

## Что это

Приложение для подготовки к **ОГЭ и ЕГЭ** по 11 предметам: математика, русский язык, история,
физика, химия, биология, география, обществознание, информатика, английский язык, литература.

Три роли в одном приложении — **ученик**, **учитель** и **администрация школы**.

**Ученику:** квест из 5 заданий, очки, серия дней, 22 достижения, прогноз оценки, разбор каждого
ответа, 45 карточек-шпаргалок по темам, работа над ошибками, «задание дня» и пробный экзамен
на 20 заданий с адаптивной сложностью.

**Учителю:** выдача задания выбранному классу, отчёты по классу с выгрузкой в таблицу,
список класса, связь с учениками.

**Работает без интернета:** 209 встроенных заданий по всем предметам (154 базовых и 55 сложных уровня ОГЭ и ЕГЭ), теория, статистика и
генератор заданий доступны офлайн. Для 9 предметов подключён открытый банк реальных заданий
ОГЭ и ЕГЭ — он запрашивается в момент решения, а скачанное сохраняется в кэш, поэтому квест
по реальным заданиям открывается и без сети.

## Установка и запуск

### Шаг 1. Получить исходный код

```bash
git clone https://github.com/Yarosl4vn/Kvestefi-2026.git
cd Kvestefi-2026/src
```

### Шаг 2. Указать путь к Android SDK

Создайте в папке `src/` файл `local.properties`:

```properties
sdk.dir=C\:\\Android\\Sdk
```

Путь замените на свой. Альтернатива — задать переменные окружения `ANDROID_HOME`
или `ANDROID_SDK_ROOT`.

### Шаг 3. Проверить JDK

```bash
java -version
```

Ожидается версия 17. Если стоит другая, укажите 17-ю:

```bash
set JAVA_HOME=C:\Program Files\Java\jdk-17      :: Windows
export JAVA_HOME=/usr/lib/jvm/jdk-17            # Linux и macOS
```

### Шаг 4. Собрать приложение

Отладочная сборка (для проверки, подписывается автоматически):

```bash
gradle assembleDebug
```

Релизная сборка (нужна подпись; ключ в репозиторий не включён — см. примечание ниже):

```bash
gradle assembleRelease
```

Если Gradle не установлен глобально, откройте папку `src/` в Android Studio
и нажмите **Run ▶** — среда сама скачает нужную версию сборщика.

### Шаг 5. Установить на устройство или эмулятор

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Готовый подписанный APK версии 4.0.0 приложен в репозитории — устанавливается сразу:
`assets/Kvestefi-4.0.0.apk`

### Примечание о подписи релизной сборки

Релизная сборка читает `keystore.properties` и ключ `kvest-release.jks`. Оба файла
**намеренно не включены в репозиторий**: они содержат пароли и закрытый ключ, а требования
хакатона запрещают публиковать конфиденциальные данные. Для проверки используйте готовый APK
из `assets/` или отладочную сборку.

## Примеры входных и выходных данных

### 1. Регистрация ученика

**Вход:** ФИО `Петров Иван Сергеевич`, дата рождения `01.09.2009`, почта `pupil@school.ru`,
школа `Школа №1, Мытищи`, класс `9А`, пароль от 8 символов.

**Выход:** аккаунт ученика в локальной базе (`users`, роль `student`, статус `подтверждён`),
сразу открывается главный экран с приветствием по имени. Проверка пароля: короче 8 символов,
только цифры или только буквы — приложение не примет и покажет надёжность пароля.

### 2. Квест

**Вход:** предмет `Математика`, 5 заданий.

**Выход:** экран результата: `4 из 5 верно`, оценка `4`, `45 очков`, время, разбор каждого
задания со ссылкой на источник, обновлённая серия дней, при выполнении условий — новое
достижение. Попытка сохраняется в `attempts` и учитывается в прогнозе оценки.

### 3. Учитель выдаёт задание

**Вход:** предмет `Математика`, уровень `ОГЭ`, тема `Геометрия`, класс `9А`, 10 задач.

**Выход:** запись в `assignments` (`subject_code`, `exam`, `topic`, `grade = 9`,
`letter = А`, `school`, список задач). Ученики этого класса видят задание в своём приложении,
результат возвращается учителю.

### 4. Отчёт по выданному заданию

**Вход:** выданное задание с результатами класса.

**Выход:** текст с разделителем `;` — его можно вставить в Excel или Google Таблицы
и отправить через «Поделиться»:

```
Ученик;Верных;Всего;Оценка;Очки;Сдано
Петров Иван Сергеевич;4;5;4;45;16.10.2026
Сидорова Анна Павловна;5;5;5;60;16.10.2026
```

### 5. Задание из открытого банка

**Вход:** предмет `Математика`, уровень `ОГЭ`.

**Выход:** условие задачи, 4 варианта ответа, верный ответ, разбор и ссылка на источник
вида `https://math-oge.sdamgia.ru/problem?id=137419`. Если сети нет, задание приходит из
сохранённого кэша, а подпись на экране честно меняется на «сохранённые задания».

## Ограничения (важно для проверки)

* **Нет общего сервера.** Аккаунты, переписка, очки и прогресс хранятся на устройстве.
  Поэтому вход в один аккаунт с разных телефонов и обмен между устройствами вне одной сети
  не поддерживаются. Режимы «дуэль» и «соревнование школ» между разными устройствами в версии
  4.0.0 не реализованы — они заявлены в плане развития.
* **Онлайн-банк требует интернета** при первом запросе: дальше задания берутся из кэша.
* **ВПР не поддерживается** — приложение готовит только к ОГЭ и ЕГЭ.
