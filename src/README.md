# Квестефи

Мобильное Android-приложение для подготовки к **ОГЭ, ЕГЭ и ВПР**: решаешь задачи в формате экзамена, держишь серию дней, берёшь реальные задания из открытого банка и повторяешь теорию по материалам из свободных источников.

- **Пакет:** `ru.readysquad.kvest`
- **Язык:** Kotlin, XML-layouts, Material 3
- **minSdk:** 24 · **targetSdk / compileSdk:** 34
- **Версия:** 4.0.0 (versionCode 40)
- **Сборка:** Gradle 8.2 · AGP 8.2.2 · Kotlin 1.9.22
- **Офлайн:** частично. 154 встроенных задания, генератор тренировки, теория, шпаргалки и статистика работают без интернета. Интернет нужен для **онлайн-банка реальных заданий**, библиотеки материалов и курсов Stepik.

## Источники материалов

### Задания: онлайн-банк + встроенный банк + генератор

**Официального API с заданиями ОГЭ/ЕГЭ не существует.** Открытые банки ФИПИ (`ege.fipi.ru/bank/`, `oge.fipi.ru/bank/`) — веб-приложения без публичного интерфейса; в открытом доступе есть только сторонние парсеры ([fipi-mcp](https://github.com/MasterGiGiK/fipi-mcp), [fipi_parser.py](https://github.com/avikiqwww/stereometry-solver-bot/pull/2)).

Поэтому работают три режима:

1. **Онлайн-банк** — `Sdamgia` (`data/Sdamgia.kt`). Реальные задания открытого образовательного портала.
   Подключено 9 предметов: математика, русский язык, история, физика, химия, биология, география, информатика, английский.
   Обществознание и литература не подключены: в этих разделах портала есть только задания с развёрнутым ответом,
   блока с кратким ответом на странице нет. Покрытие по уровням проверено запросами к порталу:
   математика ОГЭ 12/16 и ЕГЭ 16/16, русский ОГЭ 7/16 (в ЕГЭ условия на 11-19 тысяч знаков — не для карточки),
   история и физика 16/16 на обоих уровнях, география 11/16 и 16/16, информатика 16/16 и 10/16,
   английский 16/16 и 9/16, биология 9/16 и 7/16, химия 6/16 на обоих уровнях.
   Если по выбранному уровню заданий нет, приложение само берёт второй уровень. Схема: каталог предмета даёт темы (`category_id`), страница темы — ссылки на задачи, страница задачи — условие, рисунок, ответ и разбор.
   - Задания **запрашиваются в момент решения и не сохраняются** — приложение не хранит чужой банк заданий у себя.
   - Варианты ответа: у реальных заданий ответ краткий, поэтому `Sdamgia.optionsFor` строит четыре варианта — верный плюс три правдоподобных. Для чисел соседние значения, сдвиг на порядок, удвоение; для слов и названий — ответы других заданий того же раздела.
   - Рисунки грузятся по ссылке (`ImageLoader`, `Http.getImage`) — с заголовком Referer, иначе банк отдаёт изображение только со своей страницы.
   - У каждого задания показывается ссылка на источник.
   - Блоки условия, ответа и разбора ищутся с учётом вложенности тегов. Обрезать по «следующему маркеру» нельзя: между условием и разбором на странице стоят аналоги, кодификатор и реклама, и в ответ попадал весь остаток страницы.
   - Текст чистится сканером, который пропускает `>` внутри значений атрибутов: иначе обрывки скриптов из `onclick` попадали в формулировку задания.
   - Из темы берётся не больше двух заданий, иначе квест собирался бы из одной темы.
2. **Встроенный банк** — 154 задания офлайн, работают без интернета.
3. **«Тренировка»** — задания строит `TaskGenerator` кодом: проценты, уравнения, площади, среднее арифметическое, F = m·g, v = S/t, A = P·t, масса через плотность, относительная молекулярная масса, перевод в двоичную систему, биты и байты, масштаб карты.

Порядок чтения страниц банка одинаковый во всех режимах: `Sdamgia.quest()` отдаёт задания с рисунком и разбором, `QuizActivity` спрашивает выбор из четырёх вариантов, `RealTasksActivity` — ввод краткого ответа в клетки, как в бланке ответов № 1.

Контент банка принадлежит порталу. Приложение забирает небольшой объём для учебных целей и у каждого задания показывает прямую ссылку на источник.

Свой источник подключается через интерфейс `TaskSource`:

```kotlin
interface TaskSource {
    val name: String
    val isOffline: Boolean
    fun load(subjectCode: String, limit: Int): List<Task>
}
```

### Библиотека: три свободных API без ключа

| Источник | Что берём | Запрос |
|---|---|---|
| Википедия | вступление в 3 предложения, обрезается по границе предложения | `ru.wikipedia.org/w/api.php?action=query&generator=search&prop=extracts&exsentences=3` |
| Викисловарь | только раздел «Значение» — короткое толкование | `ru.wiktionary.org/w/api.php?action=query&titles=…&prop=extracts&explaintext=1` |
| Wikimedia Commons | до 4 картинок по теме (для SVG сервис отдаёт PNG-миниатюру) | `commons.wikimedia.org/w/api.php?action=query&generator=search&gsrnamespace=6&prop=imageinfo` |

Тексты — лицензия CC BY-SA. DuckDuckGo Instant Answer не используется: на русские запросы он возвращает пустой ответ.

### Курсы: открытый каталог Stepik

| Источник | Что берём | Запрос |
|---|---|---|
| Stepik | название, описание, обложка, число записавшихся, ссылка на курс | `stepik.org/api/courses?search=…&page=1` |

Ключ не нужен. Курсы не скачиваются: пользователь открывает их на сайте Stepik. Разбор ответа — `data/Stepik.kt`, битые записи пропускаются.

## Что изменилось в 4.0.0

- **Задания из открытого банка больше не приходят неполными.** Раньше условие могло показаться без рисунка или с потерянной формулой — ответ приходилось угадывать, потому что разбор отбрасывал картинку, таблицы и формулы. Теперь приложение такие задания отсеивает и не показывает в квесте, а рисунок к задаче загружается и виден прямо под условием.
- **Кэш заданий хранит рисунок и ссылку на источник.** В сохранённом наборе раньше терялись и картинка, и источник: без интернета задание приходило «слепым». Теперь сохранённое задание выглядит так же, как онлайн.
- **Убраны остатки заявок и подтверждений** — аккаунты создаются сразу, подтверждать некого: удалены карточка «Статус заявки», экран списка заявок, счётчик «Ждут подтверждения» и одобрение школ. Осталось только то, что работает на одном устройстве.

Релиз после аудита кода: найдено и исправлено семь ошибок, часть — с реальными последствиями для школы.

- **Классный руководитель не видел свой класс.** Класс хранится как «9А» без пробела, а разбор строки ждал пробел — буква класса терялась. Из-за этого в списке класса было пусто, в переписке не появлялись свои ученики, а **выданное задание уходило на всю параллель** вместо одного класса. Исправлено в трёх местах.
- **«Работа над ошибками» открывалась пустой.** Счётчик учитывал записи без задания, поэтому карточка обещала ошибки, а квест сразу закрывался с надписью «Ошибок пока нет». Теперь считаются только реальные задания, и режим открывается с ними.
- **Ученик 10–11 класса получал задания ОГЭ.** Приложение нигде не передавало уровень экзамена, и всегда подставлялся ОГЭ. Теперь уровень определяется по классу: 10–11 — ЕГЭ, остальные — ОГЭ.
- **Подбор предмета по теме срабатывал ложно.** Проверка шла поиском подстроки, поэтому короткое название темы могло совпасть с чужим предметом. Теперь сравнение идёт по названию темы целиком.
- **Обновление очень старой базы ломало аккаунты.** В ветке пересоздания базы не добавлялись колонки цвета ника и префикса, а запрос аккаунтов их уже читал — приложение падало на входе. Добавлено создание схемы.
- **Доступ администрации** больше не зависит от точной формулировки должности (из 3.4.0, подтверждено).
- **Убрано всё, что обещало серверную работу:** подтверждение заявок учителей, «с какой устройств открыт аккаунт», тексты про рассмотрение заявок разработчиками.
## Что изменилось в 3.4.0

- **ВПР убран везде.** Не осталось ни одного упоминания: фильтры уровней, тексты регистрации, описания, шеринг. Старые задания и шпаргалки с меткой ВПР автоматически становятся ОГЭ при обновлении (версия базы 23).
- **Телефон заменён на почту.** В регистрации поле называется «Почта», принимает вид pupil@school.ru, с проверкой формата. В профилях и карточках телефон больше не показывается.
- **Профиль другого пользователя как в мессенджере.** Новый экран: крупный аватар с первой буквой имени, имя с префиксом (у разработчиков красным), роль и статусы, очки, школа. Для ученика — класс и классный руководитель, для учителя — должность, предметы и классное руководство. Ниже — достижения и данные.
- **Больше цветов ника.** Добавлены кроваво-красный, ярко-зелёный, ярко-голубой, золотой, апельсиновый, аметистовый и бирюзовый — всего 15.
- **Панель разработчика: назначение ролей.** Разработчик может выдать роль и должность: ученик, учитель-предметник, классный руководитель, администрация школы, разработчик.
- **У разработчиков в профиле нет класса** — вместо школьных полей показываются префикс, роль и очки.
- **Изоляция школ.** Учителя и администрация видят только аккаунты своей школы: чужие ученики и учителя в списках не появляются.
- **Доступ администрации стал устойчивее.** Проверка должности принимает любую формулировку со словом «администра» и учитывает разработчиков, поэтому школьные экраны больше не отказывают в доступе из-за разного написания должности.
- **Убрано «Цвет ника» из блока данных** — осталось только действие в служебном разделе.
## Что изменилось в 3.3.1

### Проверка на эмуляторе Android 14
- **Исправлено падение при первом запуске.** В файле с новыми заданиями ОГЭ и ЕГЭ карта «тема → предмет» объявлялась после самих заданий, а Kotlin инициализирует поля по порядку. На чистой установке это давало `NullPointerException` и приложение не открывалось вовсе. Теперь карта строится функцией — порядок объявлений больше не важен.
- **Карточки на главной получили подписи.** Вспомогательный метод карточки рисует только две строки, а заголовок использует лишь для выбора иконки: из-за этого «Задание дня», «Пробный экзамен», «Работа над ошибками» и «Неделя» выводились без названия.
- **У карточек разные иконки** вместо одной книжки: экзамен — ракета, ошибки — лампочка, неделя — график.
- **Кнопки, прогресс и навигация теперь следуют палитре.** Была причина, по которой «не всё меняло цвет»: базовые цвета приложения были прописаны шестнадцатеричными значениями, а не взяты из темы, поэтому кнопки оставались сиреневыми при любой палитре. Теперь главные кнопки берут цвет из темы — проверено переключением на «Изумрудный».

## Что изменилось в 3.3.0

### Онлайн-задания теперь работают без интернета
- **Постоянный кэш заданий из открытого банка.** Раньше скачанные задания жили только в памяти процесса и пропадали при закрытии приложения. Теперь они сохраняются в базе: неделю считаются свежими и отдаются сразу, а если сети нет — берутся сохранённые, пусть и старые. Подпись меняется на «сохранённые задания», чтобы не было сюрпризов.

### Мотивация и режимы
- **«Задание дня».** Набор из пяти заданий определяется датой: у всех учеников в один день он одинаковый, а на следующий день меняется.
- **Пробный экзамен.** Двадцать заданий подряд — проверка себя в формате экзамена, а не короткого квеста.
- **Работа над ошибками.** Отдельный режим: собираются задания, в которых ученик ошибался, и предлагаются заново. Карточка появляется, только если ошибки есть.
- **Адаптивная сложность.** Приложение запоминает целевую сложность: после квеста с точностью 80% и выше задания становятся сложнее, после 40% и ниже — проще.
- **Закрыть слабую тему.** В статистике по предмету видна слабая тема и кнопка «Пройти слабую тему»: пять заданий строго по ней. Если решить четыре из пяти — тема считается закрытой.
- **Цель недели и челлендж.** На главной карточка «Неделя»: сколько дней из семи занимался и сколько очков из цели набрал.

### Отчёты
- **Выгрузка отчёта по заданию.** Учитель выгружает отчёт по классу: кто прошёл, результат, оценка, очки, дата. Разделитель — точка с запятой, такой файл открывается в Excel и Google Таблицах.
- **«Поделиться прогрессом».** Отчёт для родителей: точность, серия дней, очки за неделю, слабые темы, результат последнего квеста.

## Как запустить

**Вариант 1 — Android Studio**

1. Склонировать репозиторий: `git clone <адрес-репозитория>`
2. Открыть папку проекта в Android Studio.
3. Дождаться синхронизации Gradle.
4. Подключить телефон с отладкой по USB или запустить эмулятор (Android 7.0 и новее).
5. Нажать Run — приложение установится и откроется на экране приветствия.

**Вариант 2 — командная строка**

```
export JAVA_HOME=/path/to/jdk17        # Windows: set JAVA_HOME=C:\jdk17
export ANDROID_HOME=/path/to/sdk       # Windows: set ANDROID_HOME=C:\sdk
./gradlew assembleDebug                # Windows: gradlew.bat assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Готовый подписанный APK собирается командой `./gradlew assembleRelease`.
